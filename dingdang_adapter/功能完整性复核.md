# 购物功能完整性复核 · 2026-11-04

用户明确：核心为真实购物智能体及问卷，不以 demo 验收；A2UI 不纳入本轮改造。

## 基线

以用户本机 `购物智能体 2` 的现有购物代码为基线。改版父提交为 `29f9edf`，之前的购物体验快照为 `475ca7f`。改版前已跟踪工作区没有未提交的 Agent 改动。`master` 与这条分支不完全一致，不能拿 master 代替当前本机实现。

本机未跟踪的 `prototype-content-cards` 是内容展示原型，并非真实购物后端；本轮保留未跟踪材料，不覆盖或删除。真实主链路依然是 Node → Wit ShoppingAgent → 淘宝商品接口与模型服务。

## 发现并修复的新适配层问题

| 功能 | 原引擎状态 | 新界面修复 |
|---|---|---|
| 按品类生成四题问卷、自定义回答 | 保留 | 还原 step/total，不再漏掉进度；选项与文本回答均可用 |
| 预算、用途、风格等条件提取 | 保留 | 传递任务答案与偏好数据 |
| 真实商品召回、筛选、排序 | 保留 | 原淘宝代码与签名未修改 |
| AI 推荐理由、归纳、后续引导 | 保留 | 补回原字段 followUp 和 narrativeSource |
| 文案失败后保留候选、原候选重试 | 保留 | 补回 candidateItems；业务错误进入会话展示，不再直接丢弃；增加重试按钮 |
| 当前商品追问、比较 | 保留 | 使用原会话继续追问；补回商品事实字段供详情展示 |
| 新会话及显式换品类隔离 | 保留 | 保持原 Agent 的隔离规则，不增加跨会话偏好继承 |
| 历史会话、用户标识 | 保留 | 复用原浏览器用户标识；同源旧历史可出现在新版历史中并接续原会话；刷新恢复当前会话 |
| 收藏、详情、购买来源链接 | 保留 | 新界面可用；DD 沙箱内提供可选中复制的来源链接 |
| 帖子与 A2UI | 按用户要求不用于新版 | 帖子检索跳过、输出不含内容块；新增 start:desktop 不运行 A2UI 构建 |

另外修复了启动器的端口问题：原来用 `PORT=4318` 启动时，Wit 商品请求仍默认指向 3000。现在随 PORT 自动配置 WIT_PRODUCT_URL；显式配置的地址仍优先。这个问题与那一次直接调用淘宝接口的 8 秒超时是两件事。

浏览器历史按协议、主机和端口隔离。原版 `localhost:3000` 的历史不能自动从 `localhost:4318` 读取；原端口 3000 的正式入口已启动，可保留同源历史。不同端口不会被误报为数据丢失。
