# 拾光 · 沉浸式购物导购 V1

这是现有购物智能体的移动端交互重构。先在 [`prototype-yuemai/`](prototype-yuemai/) 做了可独立预览的 HTML 原型，再将页面接入 [`backend/`](backend/) 的真实商品检索。参考了悦买的交互节奏，但品牌、配色、图标和首页插画均为本项目的新设计。

## 本地运行

需要 Node.js 18+。在 `backend` 目录配置自己的 `.env`（参考 `.env.example`；不要提交密钥），然后运行：

```powershell
cd backend
npm test
npm start
```

打开 <http://localhost:3000/>。首页可点击「适合军训的防晒霜」：依次回答肤质和单件预算，看到真实搜索阶段、商品卡片、卡后归纳以及继续追问。可打开商品列表、收藏商品并从侧栏找回历史会话。

## 交付与边界

- 独立 HTML 原型：[`prototype-yuemai/index.html`](prototype-yuemai/index.html)。原型中的商品是明确标记的演示内容；正式页面使用接口结果。
- 任务图与验收：[`悦买复刻_任务图.md`](悦买复刻_任务图.md)、[`验收报告_P3.1.md`](验收报告_P3.1.md)、[`design-qa.md`](design-qa.md)。
- 防晒推荐目前主要依据预算、关键词、标题匹配；不把肤质适配或功效当成已验证事实。商品价格、链接与库存以原平台为准。
- 防晒任务状态目前保存在后端进程内，重启服务后无法接续正在进行的问卷；浏览器历史和收藏仅保存在本地浏览器。跨设备持久记忆不是此版交付内容。
- 本版完成 393×852 手机视口的关键结构核对，但没有宣称逐像素差分达标，也没有实现下单、上传附件或语音输入。
