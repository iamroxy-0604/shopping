# React A2UI 模块设计 QA

## 对照范围

- 视觉参考：用户提供的“拾光”移动端购物体验原型。
- 实现范围：`link-bridge` 独立 A2UI 实验台，不包含购物智能体页面。
- 对照状态：窄视口预览卡片、图文详情底部弹层、视频降级详情。

## 验收结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 横向帖子预览 | 通过 | 手机视口中为横向滑动卡片，封面、标题、平台、作者、互动量层级清晰。 |
| 来源差异 | 通过 | 小红书使用图片卡，B站使用播放标识与时长，知乎使用文字优先卡。 |
| 底部详情弹层 | 通过 | Radix Dialog 具备遮罩、关闭、聚焦管理和移动端底部抽屉形态。 |
| 图集滑动 | 通过 | Embla 上一张/下一张可用，页码与当前 slide 同步。 |
| 视频无可播放文件 | 通过 | 保留封面、时长和摘要，使用紧凑说明代替原始大段错误文字。 |
| 品牌主题 | 通过 | 暖橙风对齐原型的橙色、白色表面、大圆角和低对比边框。 |
| 主题切换 | 通过 | 千禧数码风可即时切换，卡片结构和 A2UI 数据不变。 |
| 浏览器控制台 | 通过 | 最终交互检查无 error/warning。 |

## 可后续微调的 P3
